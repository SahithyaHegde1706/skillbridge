# 💼 SkillBridge
SkillBridge is a modern freelance marketplace platform where clients can hire talented freelancers for web development, design, writing, marketing, and other digital services.

The platform provides separate dashboards for clients, freelancers, and admins with secure authentication, gig management, order tracking, reviews, earnings analytics, and responsive UI.

## 🚀 Features

### 👤 Authentication:-
- User Signup & Login
- JWT Authentication
- Role-based access:
  - Client
  - Freelancer
  - Admin

### 🧑‍💻 Freelancer Features:-
- Create, Edit & Delete Gigs
- Upload Gig Images
- Manage Orders
- Earnings Dashboard
- Monthly Earnings Graph
- Reviews & Ratings
- Responsive Freelancer Dashboard

### 🛒 Client Features:-
- Browse Freelance Services
- Search & Filter Gigs
- Purchase Gigs
- Leave Reviews & Ratings
- Responsive Home Page

### 🛠️ Admin Panel:-
- Admin Dashboard
- View Total Users
- Manage Gigs
- Ban / Unban Users
- Platform Revenue Analytics

## 🖥️ Tech Stack

### Frontend:-
- React.js
- React Router DOM
- Chart.js
- CSS3
- Vite

### Backend:-
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcryptjs

## ✅ Conclusion
SkillBridge successfully demonstrates a modern freelance marketplace platform built using the MERN stack. The project provides a smooth experience for clients, freelancers, and admins through role-based dashboards, secure authentication, gig management, order handling, reviews, and analytics.
The platform focuses on creating a responsive and user-friendly interface while implementing real-world full stack development concepts such as REST APIs, JWT authentication, MongoDB integration, protected routes, and dynamic frontend rendering.

This project helped in understanding complete full stack application development, responsive UI design, backend architecture, API integration, deployment, and state management.

SkillBridge can be further enhanced with features like online payments, live chat, notifications, AI-based recommendations, and advanced analytics to make it production-ready for real-world freelance marketplaces.
